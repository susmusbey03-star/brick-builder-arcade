# Brick Builder Arcade

Yüksek tempolu, sonsuz seviye mantığına sahip bir tuğla/blok yerleştirme oyunu. Amaç, blokları yerleştirerek satırları temizlemek ve puanları artırmak.

## Özellikler
- Sonsuz seviye sistemi
- Artan zorluk ve hedefler
- Can sistemi
- Sonraki blok önizleme
- Klavye ve fare desteği
- Tarayıcıda doğrudan çalışır

## Oyuncu Kontrolleri
- Sol / Sağ ok: blok kaydırma
- Aşağı ok: hızlı düşüş
- Boşluk / Yukarı ok: döndürme
- Fare tıklama: hedef konuma yerleştirme

## Nasıl Çalıştırılır?
1. Projeyi bilgisayarınıza indirin.
2. `index.html` dosyasını bir tarayıcıda açın.
3. "Oyunu Başlat" butonuna basın.

## Önerilen kullanım
Bu proje statik bir web uygulamasıdır; özel kurulum gerekmez. İsterseniz daha sonra bunu bir local server üzerinden de çalıştırabilirsiniz.

## Geliştirme Notları
Proje, sade HTML/CSS/JavaScript yapısı kullanır. Gerektiğinde kolayca genişletilebilir ve görsel efektler, sesler, menüler ve en yüksek skor sistemi eklenebilir.
